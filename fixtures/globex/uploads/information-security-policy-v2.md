# Globex Corporation Information Security Policy (v2)

## 1. Scope

This policy covers Globex staff and the systems they use.

## 2. Access

Managers approve access requests. Access is reviewed from time to time.

## 3. Passwords

Passwords must be at least eight characters.

## 4. Incidents

Report suspected incidents to the IT helpdesk.

## 5. Training

New starters watch the security induction video.
