04 · Flowchart · CCP target architecture

How evidence becomes a verdict

Every path ends in a verdict that code wrote. Gaps in the data abstain as needs_review; a model's only job is to fill typed fields that code checks before a rule reads them.

TIER 1

Rules over facts

  • Pure functions over observations, keyed by rule version and pinned inputs.
  • Tier 1 never waits on a model budget.

TIER 2

Extract, then rule

  • Haiku 5.5 fills a typed schema with pointer citations (segment ids, JSON Pointers). Code checks each one, then a rule decides.
  • A refusal or failed check gives needs_review. A second reader runs before any AI-derived PASS.

ROLLUP

Over who should be there

  • The rollup counts the expected population, not only rows that exist, and marks stale or unassessed subjects.
  • No PASS over a partial or stale population.
